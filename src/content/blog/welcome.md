## 以后怎么发文？

1. 在 `src/content/blog/` 下新建一个 `.md` 文件  
2. 写好标题、摘要、日期（front matter）  
3. 用 Markdown 写正文  
4. `git add` → `git commit` → `git push`  
5. 等 GitHub Actions 部署完成后，文章就会出现在网站上

## Markdown 示例

你可以写**加粗**、*斜体*，也可以写列表：

- 生活随笔
- 读书笔记
- 技术分享
